# 屿账 v0.8.1 · Windows 应用启动版

下载附件 **shujuku-windows-x64.zip**，全部解压，双击“屿账”文件夹中的 **屿账.exe**。首次启动稍候，之后自动打开浏览器；用完点击启动窗口的“退出应用”。不需要安装 Python 或 MySQL，也不需要命令行。

请保留 exe 旁边的 mysql 文件夹，不要只复制 exe。个人数据保存在 `%LOCALAPPDATA%\Shujuku\data`，正常退出和再次启动后保留。

本次新增和修复：

- 原生 Windows 启动窗口，提供打开应用、查看日志和退出按钮。
- 自动准备数据库、示例数据和本地服务；重复双击复用已有窗口。
- 修复 tkinter 缺失、MySQL 中文发布路径和退出后服务残留。
- 随包提供 MySQL 运行文件与原始许可证，使用原生 SQL。

真实 EXE 七项验收通过，覆盖去除开发工具 PATH 后启动、首次建库、重复双击、安全退出、重启数据保留、浏览器展示和端口释放。验收发生在开发者当前 Windows 机器，尚未覆盖另一台干净 Windows 机器。

本版仍是第 8 周课程演示版本，初始数据均为虚构；取消事务、触发器、存储过程等后续业务功能尚未实现。GitHub 自动附带的 Source code 下载项是源码，直接使用请选择上面的 Windows 应用附件。
